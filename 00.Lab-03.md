# Week 3 Lab: Auditing a Model for Bias

## Objectives

By the end of this lab you will be able to:

- Split a model's behaviour by a protected attribute and read a **per-group confusion matrix**.
- Measure the standard **group-fairness metrics** with Fairlearn: selection rate, demographic parity, disparate impact, equalised odds, and calibration.
- Test empirically whether **"fairness through unawareness"** actually works on your data, rather than assuming it does.
- Demonstrate the **impossibility result** with your own numbers: show that two reasonable fairness criteria cannot both be satisfied when base rates differ.
- Attempt one **mitigation** and quantify its cost honestly, in accuracy *and* in the fairness metric it does not fix.
- Draft a short **ethical-impact assessment** that a sceptical stakeholder would accept.

This lab uses the same UCI Credit Card dataset and the same model you built in Week 2. We are not building a new model; we are putting the one you already have on trial.

## Prerequisites

- The Week 2 lab, or at least the leakage-safe pipeline and the logistic-regression classifier from it.
- Python with `numpy`, `pandas`, `scikit-learn`, `scipy`, `matplotlib`, and one new library, `fairlearn` (`pip install fairlearn`).
- The file `UCI_Credit_Card.csv` in your working directory. It is the same file as Weeks 1 and 2, and it is in **Week 03 Lab Files** on this unit if you need it again.

A note before we start. In this dataset the target is `default` (1 = the customer defaults next month). In machine-learning terms the *positive class* is "default", which is the **adverse** outcome. The **favourable** outcome, the one a fairness law cares about, is being *approved*, that is, *predicted not to default*. Keep that distinction in mind: throughout this lab, `approve = (prediction == 0)`. Confusing the positive class with the favourable outcome is the single most common mistake in a first fairness audit.

## Lab Setup

Run this once. It rebuilds the Week 2 model and leaves everything the rest of the lab needs in memory. Notice one deliberate change from Week 2: **we drop `SEX` from the model's inputs.** The model never sees it. That is "fairness through unawareness", and Section 4 tests whether it worked.

```python
# setup.py
import warnings; warnings.filterwarnings("ignore")
import numpy as np, pandas as pd
import matplotlib.pyplot as plt
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

# --- load and clean exactly as in Week 2 ---
df = (pd.read_csv("UCI_Credit_Card.csv")
        .rename(columns={"default.payment.next.month": "default", "PAY_0": "PAY_1"}))
df["EDUCATION"] = df["EDUCATION"].replace({0: 4, 5: 4, 6: 4})
df["MARRIAGE"]  = df["MARRIAGE"].replace({0: 3})
df = df.drop(columns=["ID"])

# --- feature groups: note SEX is NOT in the model ---
pay    = [f"PAY_{i}" for i in range(1, 7)]
bill   = [f"BILL_AMT{i}" for i in range(1, 7)]
payamt = [f"PAY_AMT{i}" for i in range(1, 7)]
num    = ["LIMIT_BAL", "AGE"] + pay + bill + payamt
cat    = ["EDUCATION", "MARRIAGE"]          # SEX deliberately excluded

prep = ColumnTransformer([
    ("num", StandardScaler(), num),
    ("cat", OneHotEncoder(handle_unknown="ignore"), cat),
])

X, y = df[num + cat], df["default"]
# keep SEX aside as the sensitive attribute (1 = male, 2 = female)
X_tr, X_te, y_tr, y_te, sex_tr, sex_te = train_test_split(
    X, y, df["SEX"], test_size=0.25, random_state=0, stratify=y)

clf = Pipeline([("prep", prep), ("model", LogisticRegression(max_iter=2000))]).fit(X_tr, y_tr)

# the score (probability of default) and the sensitive feature for the test set
scores = clf.predict_proba(X_te)[:, 1]
sex    = sex_te.map({1: "male", 2: "female"}).values
y_true = y_te.values

from sklearn.metrics import accuracy_score, roc_auc_score
y_hat = (scores >= 0.5).astype(int)          # default decision at the 0.5 threshold
print(f"accuracy {accuracy_score(y_true, y_hat):.3f}   "
      f"AUC {roc_auc_score(y_true, scores):.3f}   "
      f"default base rate {y.mean():.3f}")
```

You should see accuracy **0.812**, AUC **0.712**, base rate **0.221**. This is the model. Now we audit it.
