# Going Further (optional)

Not graded. For people who finished and want more.

- **Eigenvectors by hand.** For A = [[2, 1], [1, 2]], find the two directions that only get stretched, and their stretch factors. Check with `np.linalg.eigh`.
- **Your PCA in your capstone.** Copy `my_pca` into `src/scratch/pca_svd.py` in your project repository as `pca`, and run `python -m pytest -q`: the three PCA tests should pass.
- **Bits or nats.** Recompute Table C in bits by dividing by ln 2 (0.693). Which unit does PyTorch use?
- **Another way to count dimensions.** Look up the TwoNN estimator (Facco and others, 2017): it uses each point's nearest and second-nearest neighbours. Does it agree with your 90% count for the digits?
- **Read more.** The Week 8 core booklet works every example on paper.
