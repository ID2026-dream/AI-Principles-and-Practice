# Week 9 Reference Answers

Go through this beside your own sheet. For each question you get the reference answer with the numbers from a
reference run, why, and for predictions, the tempting answer and what makes it tempting. Your numbers should match
to the first decimal place: everything is seeded.

## The five predictions people get wrong most often

| Question | The tempting answer | What actually happens |
|---|---|---|
| **1a** | The digits are the same, so about 95% | 71%: the backbone never saw noise or blots |
| **2a** | A fresh network fits 50 examples perfectly, so it wins | 55% against 71%: it memorises 50 examples and generalises badly |
| **2c** | Scratch needs about 1,000 labels per digit | About 20 to 40 per digit, here |
| **3b** | Fine-tuning everything must be far better | 74% against 73% (LoRA) and 71% (probe) |
| **4b** | Any extra copies help | Noisy copies: 82%; upside-down copies: 55%, worse than none |
