# The Spine

The argument for teaching fundamentals first is that they get spent later. Each
row is a specific debt and where it is repaid.

| Taught earlier | Pays off later as |
|---|---|
| Data types, distributions, EDA (Wk 1) | Data-centric AI and augmentation (Wk 9) |
| Train/test, overfitting, evaluation (Wk 2) | Honest benchmarking of foundation models (Wk 9) |
| Bias and fairness (Wk 3) | The fairness audit in the final project |
| Safety, governance and explainability (Wk 4) | The model card and governance note in the final project |
| PCA and embeddings (Wk 5) | Representation learning and where bias hides (Wk 10) |
| Neuron to MLP, backprop, training dynamics (Wk 7) | Every deep model in the second half; neural ODEs (Wk 11) |
| SVD and low-rank structure (Wk 8) | LoRA and parameter-efficient fine-tuning (Wk 9) |
| Cross-entropy as information (Wk 8) | Diffusion and generative objectives (Wk 11) |

If a week in the second half feels like it arrived without foundation, the
left-hand column is where to look.
