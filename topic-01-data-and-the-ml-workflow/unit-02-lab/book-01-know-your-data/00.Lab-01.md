# Week 1 Lab: Know Your Data

## Objectives

By the end of this 90-minute lab, you'll be able to:

- Profile an unfamiliar dataset: its shape, its variable types, and what each column actually means
- Audit a dataset against its own documentation, and find the codes that aren't in the codebook
- Summarise a column's centre, spread and shape, and say when the mean is the wrong answer
- Read Pearson against Spearman, and spot the relationship a single coefficient hides
- Diagnose missingness, including missingness that has been disguised as a valid value
- Flag outliers with the IQR and z-score rules, and decide what to do about them (rarely: delete)
- Augment a scarce class with SMOTE, on the training split only
- Build a leakage-safe `ColumnTransformer` + `Pipeline` you'll reuse for the rest of the module
- Write a data dictionary and a short datasheet, and explain why that's an ethics task

## Prerequisites

- The Week 1 lecture and booklet, *Data Analysis and the ML Workflow*
- Python 3.9+ with `numpy`, `pandas`, `scipy`, `scikit-learn`, `matplotlib` and `imbalanced-learn`
- The data file `UCI_Credit_Card.csv`, provided with this lab

> **Dataset and provenance.** We use the **UCI "Default of Credit Card Clients"** dataset: Yeh, I. and Lien, C. (2009), *UCI Machine Learning Repository*, [https://doi.org/10.24432/C55S3H](https://doi.org/10.24432/C55S3H), licensed **CC BY 4.0**. It records 30,000 credit-card clients of a Taiwanese bank over April–September 2005. You will meet this dataset again in **Week 2**, where you'll model it, and in **Week 3**, where you'll audit a model of it for fairness. That's deliberate: the profiling you do today is what makes next week's modelling honest, and the things you notice today are the things that will matter then.

Get the data loaded and confirm it's the file you expect before you go further:

```python
# setup.py

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

print(df["default.payment.next.month"].mean().round(3))   # ~0.221 default rate
```

If that prints `(30000, 25)` and a default rate around `0.221`, you're ready. If not, check the CSV is in your working directory.
