## Troubleshooting

**`FileNotFoundError` on the CSV?**
- Check `UCI_Credit_Card.csv` is in the same folder you're running from, or pass the full path.

**`ModuleNotFoundError: No module named 'imblearn'`?**
- Run `pip install imbalanced-learn`. Note the package name differs from the import name.

**`SMOTE` complains about missing values or strings?**
- SMOTE needs numeric input with no blanks. That's why Section 5 uses only the numeric columns, and why Section 6 puts the imputer before it in the pipeline.

**Different numbers from the ones quoted?**
- Small differences are fine; set `random_state=0` on every split and model to match the lab closely. The counts in Sections 1–4 involve no randomness at all, so those should match exactly.

**Plots not appearing?**
- In a script you need `plt.show()`; in Jupyter, add `%matplotlib inline` at the top.
