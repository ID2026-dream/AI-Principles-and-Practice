# Week 2 Lab: Supervised Learning in Practice

## Objectives

By the end of this 90-minute lab, you'll be able to:

- Frame a real problem as either regression or classification, and justify the target from the question
- Build and reuse a leakage-safe preprocessing pipeline for mixed numeric and categorical data
- Train a simple baseline and stronger models, and compare them on the terms that matter
- Diagnose over- and underfitting from learning and validation curves, and say what to change
- Read a confusion matrix, precision, recall, F1, ROC and PR curves, and show where headline accuracy lies
- Tune a decision threshold to match the real cost of each kind of mistake

## Prerequisites

- The Week 1 lab, where you profiled this same dataset (EDA, types, distributions, the missingness wrinkle)
- Python 3.9+ with `numpy`, `pandas`, `scikit-learn` and `matplotlib`
- The data file `UCI_Credit_Card.csv`, provided with this lab

> **Dataset and provenance.** We use the **UCI "Default of Credit Card Clients"** dataset: Yeh, I. and Lien, C. (2009), *UCI Machine Learning Repository*, [https://doi.org/10.24432/C55S3H](https://doi.org/10.24432/C55S3H), licensed **CC BY 4.0**. It records 30,000 credit-card clients of a Taiwanese bank over April–September 2005. This is the *same* dataset you met in Week 1, which is deliberate: you already know it, so today you can spend your attention on the modelling rather than on getting acquainted. It's also available programmatically via the `ucimlrepo` package (`fetch_ucirepo(id=350)`) and on Kaggle here: https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset

## Lab Setup

Get the data loaded and confirm it's the file you expect before you go further:

```python
# setup.py
import pandas as pd
import numpy as np

df = pd.read_csv("UCI_Credit_Card.csv")
print(df.shape)                 # (30000, 25)
print(df["default.payment.next.month"].mean().round(3))   # ~0.221 default rate
```

If that prints `(30000, 25)` and a default rate around `0.22`, you're ready. If not, check the CSV is in your working directory.
