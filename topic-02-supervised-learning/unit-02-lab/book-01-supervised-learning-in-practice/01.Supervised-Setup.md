## Exercise 1.1: Make the data model-ready

In Week 1 you found that some category codes aren't in the documentation: `EDUCATION` has stray values 0, 5 and 6, and `MARRIAGE` has a 0. A model doesn't know those are dubious; it will happily treat them as real categories. So we fold them into the "other" bucket, and tidy the column names while we're here.

**Step 1:** Clean the codes and rename for sanity:

```python
# section1_prep.py
df = df.rename(columns={"default.payment.next.month": "default", "PAY_0": "PAY_1"})
df["EDUCATION"] = df["EDUCATION"].replace({0: 4, 5: 4, 6: 4})   # undocumented -> "other"
df["MARRIAGE"]  = df["MARRIAGE"].replace({0: 3})                # undocumented -> "other"
df = df.drop(columns=["ID"])                                    # an identifier, not a feature
```

## Exercise 1.2: One table, two questions

The same table can answer more than one question, and *which* question you ask is a modelling decision, not a property of the data.

**Task:** Look at the columns and decide which is the natural target for each of these questions. Write your answer down before reading on.

- "Will this client default next month?"
- "What credit limit did the bank grant this client?"

The first is a **category** (yes/no), so it's a *classification* target: `default`. The second is a **number** on a scale, so it's a *regression* target: `LIMIT_BAL`. We'll build both today, because the assignment will ask you to make exactly this framing call and defend it.

**Step 1:** Wire up a leakage-safe pipeline you can reuse. Scaling and encoding are fit *inside* the pipeline, so they only ever learn from training rows:

```python
# section1_pipeline.py
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder

def build_prep(numeric_cols, categorical_cols):
    return ColumnTransformer([
        ("num", StandardScaler(), numeric_cols),
        ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_cols),
    ])
```

**Reflection:** Why does the scaler have to live *inside* the pipeline rather than being applied to the whole dataframe first? If you're not sure, this is the leakage point from Week 1, worth pinning down now, because the assignment marks it.
