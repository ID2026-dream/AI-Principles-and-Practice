## Exercise 3.1: Fit the roster

**Step 1:** Predict `default`, stratifying the split so the 22% default rate is preserved on both sides:

```python
# section3_classification.py
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score

num_c = ["LIMIT_BAL", "AGE"] + [f"PAY_{i}" for i in range(1,7)] \
        + [f"BILL_AMT{i}" for i in range(1,7)] + [f"PAY_AMT{i}" for i in range(1,7)]
Xc, yc = df[num_c + categorical], df["default"]
Xc_tr, Xc_te, yc_tr, yc_te = train_test_split(Xc, yc, test_size=0.25, random_state=0, stratify=yc)

models = {
    "logistic": LogisticRegression(max_iter=2000),
    "tree":     DecisionTreeClassifier(max_depth=4, random_state=0),
    "forest":   RandomForestClassifier(n_estimators=200, random_state=0, n_jobs=-1),
    "histgb":   HistGradientBoostingClassifier(random_state=0),
}
for name, clf in models.items():
    m  = Pipeline([("prep", build_prep(num_c, categorical)), ("clf", clf)]).fit(Xc_tr, yc_tr)
    p  = m.predict(Xc_te)
    pp = m.predict_proba(Xc_te)[:, 1]
    print(f"{name:9s} acc={accuracy_score(yc_te,p):.3f} prec={precision_score(yc_te,p):.3f} "
          f"rec={recall_score(yc_te,p):.3f} F1={f1_score(yc_te,p):.3f} AUC={roc_auc_score(yc_te,pp):.3f}")
```

**Question:** Every model scores about 81% accuracy. Sounds good. Now look at the **recall** column: logistic catches just **24%** of the clients who actually default. If the bank's whole reason for building this is to spot defaulters before they default, is an 81%-accurate model that misses three-quarters of them any use? Sit with that gap between accuracy and recall — it's the door into Section 5, and it's exactly the argument the assignment wants you to make.
