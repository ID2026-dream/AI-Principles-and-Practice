# Section 4: Loss and the bias–variance trade-off

## What You'll Learn

A bad score has two opposite causes (too simple, or too flexible), and you have to tell them apart before you can fix anything. Two curves do the diagnosis.

## Exercise 4.1: Learning curve

**Step 1:** Grow a decision tree with no depth limit (so it overfits on purpose) and watch training and validation scores as the data grows:

```python
# section4_learning_curve.py
from sklearn.model_selection import learning_curve

est = Pipeline([("prep", build_prep(num_c, categorical)),
                ("clf", DecisionTreeClassifier(max_depth=None, random_state=0))])
sizes, train, val = learning_curve(est, Xc, yc, cv=5,
                                   train_sizes=np.linspace(0.1, 1.0, 6),
                                   scoring="roc_auc", n_jobs=-1)
plt.plot(sizes, train.mean(1), marker="o", label="training")
plt.plot(sizes, val.mean(1),   marker="o", label="validation")
plt.xlabel("training-set size"); plt.ylabel("ROC-AUC"); plt.legend(); plt.show()
```

You'll see the training AUC pinned near **1.00** while validation sits around **0.61**, and the gap never closes.

**Task:** Name the failure mode, and write down the three things you could do about it. (Hint: the gap is the tell, and "collect more data" is only one of the three.)

## Exercise 4.2: Validation curve

**Step 1:** Now hold the data fixed and vary one knob, the tree's depth, to find where it stops helping:

```python
# section4_validation_curve.py
from sklearn.model_selection import validation_curve

depths = [1, 2, 3, 4, 6, 8, 12, None]
train, val = validation_curve(
    Pipeline([("prep", build_prep(num_c, categorical)),
              ("clf", DecisionTreeClassifier(random_state=0))]),
    Xc, yc, param_name="clf__max_depth", param_range=depths,
    cv=5, scoring="roc_auc", n_jobs=-1)

for d, v in zip(depths, val.mean(1)):
    print(f"max_depth={str(d):>4}  validation AUC={v:.3f}")
```

**Task:** Where does validation AUC peak? What's happening to the *right* of that peak: as the tree gets deeper, validation AUC does what, and why? This peak is the bottom of the bias–variance U for this knob.
