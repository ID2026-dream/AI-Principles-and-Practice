## Exercise 5.1: Stop trusting one split

**Step 1:** Cross-validate the logistic model, scoring on AUC:

```python
# section5_crossval.py
from sklearn.model_selection import cross_val_score

pipe = Pipeline([("prep", build_prep(num_c, categorical)),
                 ("clf", LogisticRegression(max_iter=2000))])
scores = cross_val_score(pipe, Xc, yc, cv=5, scoring="roc_auc")
print(scores.round(3), " mean =", scores.mean().round(3), " std =", scores.std().round(3))
```

You'll get a mean AUC around **0.72** with a small spread. The spread is the honesty: it tells you how much your one number could have wobbled. Note the scaler and encoder are refit inside every fold, so no leakage.

## Exercise 5.2: The accuracy trap, and the confusion matrix

**Step 1:** Compare the model's accuracy with the laziest possible baseline:

```python
# section5_accuracy_trap.py
print("model accuracy (logistic):", 0.812)
print("'always predict no-default' accuracy:", round(1 - yc_te.mean(), 3))   # ~0.779
```

The model scores 0.812; predicting "no-default" for *everyone*, with no model at all, scores 0.779. Almost all of that headline accuracy is just the class imbalance.

**Step 2:** Look at *where* the mistakes fall:

```python
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay
logit = pipe.fit(Xc_tr, yc_tr)
cm = confusion_matrix(yc_te, logit.predict(Xc_te))
print(cm)   # [[TN, FP], [FN, TP]]
ConfusionMatrixDisplay(cm, display_labels=["no default", "default"]).plot(); plt.show()
```

You'll find roughly **1,264 false negatives** (real defaulters the model waved through) against **395** it caught. **Question:** which of the two errors costs the bank more, a missed defaulter or a false alarm on a good customer? The confusion matrix, not the accuracy score, is where that question lives.

## Exercise 5.4: The threshold is a dial

**Step 1:** The default 0.5 cut-off is a convention. Move it and watch the trade-off:

```python
# section5_threshold.py
for t in [0.5, 0.3, 0.2]:
    pred = (pp >= t).astype(int)
    print(f"threshold {t}:  recall = {recall_score(yc_te, pred):.3f}  "
          f"precision = {precision_score(yc_te, pred):.3f}")
```

You'll see recall climb from **0.24** at 0.5 to about **0.68** at 0.2, while precision falls from 0.73 to about 0.32. Lowering the bar catches far more defaulters, at the price of more false alarms.
