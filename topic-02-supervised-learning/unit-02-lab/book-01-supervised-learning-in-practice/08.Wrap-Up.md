## Key Takeaways

1. **The question sets the target, the target sets the metric, the metric sets the threshold.** Defaults decide none of these for you.
2. **Accuracy is the flattering number.** On an imbalanced problem it can sit barely above "predict the majority and go home".
3. **Recall and precision name the two errors.** Decide which one your problem can least afford *before* you optimise anything.
4. **Every model has one real knob, capacity.** Learning and validation curves tell you which way to turn it.
5. **Cross-validate the whole pipeline.** One split is an anecdote, five folds are evidence.

## Troubleshooting

**`FileNotFoundError` on the CSV?**
- Check `UCI_Credit_Card.csv` is in the same folder you're running from, or pass the full path.

**Different numbers from the ones quoted?**
- Small differences are fine and expected; make sure you set `random_state=0` on the split and models to match the lab closely.

**`ConvergenceWarning` from logistic regression?**
- Harmless here, but raise `max_iter` (we use 2000) or check your scaling is inside the pipeline.

**Everything is slow?**
- The random forest and learning curves are the heavy steps; `n_jobs=-1` uses all cores, and you can drop `n_estimators` to 100 while experimenting.
