# Section 1: One model, two groups

## What You'll Learn

The entire machinery of quantitative fairness is one idea: compute the confusion matrix **per group** and compare. Everything else is a name for a particular comparison.

## Exercise 1.1: The two group confusion matrices

```python
# section1_group_confusion.py
from sklearn.metrics import confusion_matrix

for g in ["male", "female"]:
    m = sex == g
    tn, fp, fn, tp = confusion_matrix(y_true[m], y_hat[m], labels=[0, 1]).ravel()
    n = m.sum()
    print(f"{g:7s} n={n:5d}  base default={y_true[m].mean():.3f}  "
          f"TN={tn} FP={fp} FN={fn} TP={tp}")
```

You will see something worth pausing on. The two groups have **different base default rates**: male **0.244**, female **0.206**. That four-point gap is not a modelling artefact; it is in the world the data records. Hold onto it. By Section 5 it is the reason the model cannot be made fair on every criterion at once.

## Exercise 1.2: The per-group table in one call

Fairlearn's `MetricFrame` computes any set of metrics for every group at once. This is the workhorse of the whole lab.

```python
# section1_metricframe.py
from fairlearn.metrics import (MetricFrame, selection_rate,
                               true_positive_rate, false_positive_rate, count)

mf = MetricFrame(
    metrics={"count": count,
             "flag_rate": selection_rate,     # P(predict default) = decline rate
             "tpr": true_positive_rate,       # of true defaulters, share caught
             "fpr": false_positive_rate},     # of non-defaulters, share wrongly flagged
    y_true=y_true, y_pred=y_hat, sensitive_features=sex)

print(mf.by_group)
```

`flag_rate` is the rate at which each group is **predicted to default**, that is, declined. Remember the favourable outcome is the opposite: `approve = 1 - flag_rate`. We will use approval for the parity metrics in Section 2 and the flag-based error rates (`tpr`, `fpr`) in Section 3.
