# Section 2: Group fairness, and a comfortable green light

## What You'll Learn

Demographic parity and its legal cousin, the four-fifths rule. And a warning: the first metric you compute will tell you the model is fine. Do not believe it yet.

## Exercise 2.1: Demographic parity and disparate impact

```python
# section2_parity.py
approve = {g: 1 - mf.by_group.loc[g, "flag_rate"] for g in ["male", "female"]}
print(f"approval rate  male {approve['male']:.3f}   female {approve['female']:.3f}")

dp_gap = abs(approve["male"] - approve["female"])
di = min(approve.values()) / max(approve.values())
print(f"demographic-parity gap {dp_gap:.3f}")
print(f"disparate impact (four-fifths) ratio {di:.3f}   "
      f"{'PASS' if di >= 0.80 else 'FAIL'} (floor 0.80)")
```

The result is a **demographic-parity gap of about 0.005** and a **disparate-impact ratio of about 0.995**. On the four-fifths rule this model passes comfortably, nowhere near the 0.80 floor.

A weak audit stops here, writes "no disparate impact detected", and signs off. That would be a mistake, and the rest of this lab is about why.

## Exercise 2.2: The green light is threshold-dependent

The 0.5 threshold is a convention. Lending decisions rarely use it. Re-run the parity check at a stricter operating point and watch the ratio move.

```python
# section2_threshold.py
for t in (0.5, 0.3, 0.2):
    yh = (scores >= t).astype(int)
    ap = {g: (yh[sex == g] == 0).mean() for g in ["male", "female"]}
    di_t = min(ap.values()) / max(ap.values())
    print(f"threshold {t}:  approve male {ap['male']:.3f} female {ap['female']:.3f}  "
          f"DI {di_t:.3f}")
```

The ratio stays above 0.80 across these thresholds here, but it *moves*, and on another dataset it can cross the floor. The lesson is durable: **a single fairness number at the default threshold is not an audit.** A disparate-impact ratio is a property of an operating point, not of a model.
