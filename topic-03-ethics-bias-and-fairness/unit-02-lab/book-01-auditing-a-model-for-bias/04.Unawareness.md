# Section 4: Did dropping the column actually work?

## What You'll Learn

"Fairness through unawareness" is the claim that removing the sensitive attribute makes the model fair. Whether it works is an **empirical question**, and you should always test it rather than assume it.

## Exercise 4.1: Can the model's own score reveal sex?

The model never saw `SEX`. But if its inputs are proxies for sex, the sensitive attribute is still *in there* through redundant encoding. Test it: try to predict sex from the model's features, and compare to simply guessing the majority.

```python
# section4_leakage.py
from sklearn.linear_model import LogisticRegression as LR

is_female = (sex_te == 2).astype(int)
probe = Pipeline([("prep", prep), ("m", LR(max_iter=2000))]).fit(X_tr, (sex_tr == 2).astype(int))
recover = probe.score(X_te, is_female)
majority = max(is_female.mean(), 1 - is_female.mean())
print(f"recover sex from features: {recover:.3f}   "
      f"majority-guess baseline: {majority:.3f}   "
      f"lift: {recover - majority:+.3f}")
```

Here the probe reaches about **0.60**, and the majority-guess baseline is also about **0.60**: **essentially zero lift.** On this dataset, the payment and billing features do **not** encode sex. Dropping the column genuinely removed it.

This is an honest and important result, and it is the opposite of what a synthetic textbook example (or the lecture's credit model) shows. The point is not "unawareness always works" or "unawareness never works". The point is that **you do not know until you measure**, and a responsible audit measures.
