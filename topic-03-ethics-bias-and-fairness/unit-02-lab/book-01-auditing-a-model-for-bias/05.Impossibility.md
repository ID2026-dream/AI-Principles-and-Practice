## Exercise 5.1: Enforce each criterion in turn

Fairlearn's `ThresholdOptimizer` post-processes the model to satisfy a chosen fairness constraint by picking per-group thresholds. Run it twice, once for demographic parity, once for equalised odds, and measure *both* gaps each time.

```python

from fairlearn.postprocessing import ThresholdOptimizer

def both_gaps(yh, label):
    d = demographic_parity_difference(y_true, yh, sensitive_features=sex)
    e = equalized_odds_difference(y_true, yh, sensitive_features=sex)
    acc = accuracy_score(y_true, yh)
    print(f"{label:24s} accuracy {acc:.3f}   DP-gap {d:.3f}   EO-gap {e:.3f}")
    return acc, d, e

both_gaps(y_hat, "as trained (0.5)")
for con in ["demographic_parity", "equalized_odds"]:
    to = ThresholdOptimizer(estimator=clf, constraints=con,
                            objective="accuracy_score",
                            predict_method="predict_proba", prefit=True)
    to.fit(X_te, y_true, sensitive_features=sex)
    yh = to.predict(X_te, sensitive_features=sex, random_state=0)
    both_gaps(yh, f"enforce {con}")
```

Read the three lines together:

| Configuration | Accuracy | DP-gap | EO-gap |
|---|---|---|---|
| as trained (0.5) | 0.812 | 0.005 | 0.017 |
| enforce demographic parity | 0.818 | **0.000** | **0.031** |
| enforce equalised odds | 0.817 | **0.010** | **0.006** |

There it is, in your own output. Force demographic parity to zero and the equalised-odds gap **nearly doubles**. Force equalised odds down and the demographic-parity gap **doubles**. You cannot drive both to zero, because the two groups have different base default rates and the model is calibrated. This is the Kleinberg and Chouldechova result, not as a slide, but as three rows of a table you generated.
