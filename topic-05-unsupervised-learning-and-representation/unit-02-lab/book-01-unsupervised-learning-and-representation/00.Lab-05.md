# Week 5 Lab: Unsupervised Learning and the Idea of a Representation

## Objectives

By the end of this 90-minute lab, you'll be able to:

- Build an unsupervised representation of a dataset whose answer column you have deliberately removed, and say plainly what "no label" changes about the task
- Cluster with K-means, read the elbow and the silhouette against each other, and defend a choice of K rather than let the code pick it
- Contrast K-means, hierarchical and Gaussian-mixture clustering by the assumption each one smuggles in, and say what internal validity can and cannot certify
- Apply PCA, read the scree plot honestly, and name a principal component in the language of the domain instead of leaving it as "PC1"
- Test whether a protected attribute you dropped is still recoverable from the representation, and interpret a negative result as carefully as a positive one
- Judge, on real numbers, whether "we just dropped the sensitive column" is a fairness claim or only a claim about your schema

## Prerequisites

- The Week 2 lab, where you built the default classifier, and the Week 3 and 4 labs, where you audited and explained it across `SEX`
- Python 3.9+ with `numpy`, `pandas`, `scikit-learn`, `scipy` and `matplotlib`. Nothing beyond the base stack is needed this week; the clustering, PCA and silhouette tools all live in scikit-learn, and the dendrogram in SciPy
- The data file `UCI_Credit_Card.csv`, provided with this lab. It is the same file as Weeks 1 to 4, and it is in **Week 05 Lab Files** on this unit if you need it again
