# Section 1: Learning without labels, and the dataset with its answer removed

## What You'll Learn

Unsupervised learning is not supervised learning with the labels hidden. It is a different question. Supervised asks "can I reproduce the known answer?"; unsupervised asks "what shape does this data make, and is that shape worth anything?". This section builds the representation you will spend the rest of the lab clustering, projecting and interrogating, and it makes one decision explicit from the start: we remove the protected attribute `SEX` on purpose, so that Section 6 can ask whether the data quietly hands it back.

**Step 2:** Build the representation. Scale the numeric features and one-hot the two categoricals, using the same leakage-safe `ColumnTransformer` idea as Week 2. Note what is *not* in the feature list: `default` (the label, because we are unsupervised) and `SEX` (the protected attribute, which we drop on purpose).

```python
# section1_build.py
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder

numeric = (["LIMIT_BAL", "AGE"]
           + [f"PAY_{i}"     for i in range(1, 7)]
           + [f"BILL_AMT{i}" for i in range(1, 7)]
           + [f"PAY_AMT{i}"  for i in range(1, 7)])
categ = ["EDUCATION", "MARRIAGE"]              # SEX is deliberately NOT here

prep = ColumnTransformer([("num", StandardScaler(), numeric),
                          ("cat", OneHotEncoder(handle_unknown="ignore"), categ)])
X  = df[numeric + categ]
Xt = prep.fit_transform(X)
Xt = Xt.toarray() if hasattr(Xt, "toarray") else Xt
feat_names = [n.split("__", 1)[1] for n in prep.get_feature_names_out()]
print("representation:", Xt.shape)             # (30000, 27)

# keep SEX aside, never fed to any model, only used to test recovery in Section 6
sex = (df["SEX"] == 2).astype(int).values      # 1 = the majority group (female)
```

`Xt` is now your representation: 30,000 clients described by 27 standardised numbers, with no label and no `SEX` anywhere in it. Everything from here runs on `Xt`.
