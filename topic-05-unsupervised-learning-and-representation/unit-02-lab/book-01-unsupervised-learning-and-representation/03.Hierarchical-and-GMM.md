# Section 3: Hierarchical, Gaussian mixtures, and the limits of validity

## What You'll Learn

K-means is one theory of what a cluster is: equal round balls, hard assignment. Two other methods encode different theories, and knowing their assumptions is worth more than memorising their code. This section meets both, then draws the line that matters for the rest of the lab: what a validity score can, and cannot, certify.

## Exercise 3.1: Hierarchical clustering hands you the scissors

Where K-means makes you pick `K` up front, hierarchical clustering builds the whole tree of merges and leaves the cut to you.

```python
# section3_dendrogram.py
import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import linkage, dendrogram

sub = np.random.default_rng(42).choice(len(Xt), size=500, replace=False)
Z_link = linkage(Xt[sub], method="ward")
plt.figure(figsize=(9, 4))
dendrogram(Z_link, no_labels=True)
plt.title("Ward dendrogram (500 clients)"); plt.ylabel("merge distance")
plt.tight_layout(); plt.show()
```

**Question:** The height of each join is how much cohesion that merge cost. Slicing the tree at different heights gives you different numbers of clusters. Who chooses the height, the algorithm or you? Write the one-sentence answer, because it is the whole point of the method.

## Exercise 3.2: A Gaussian mixture gives a probability, not a verdict

K-means says "you are in cluster 1, full stop". A Gaussian mixture returns the *probability* that each client belongs to each component, and models clusters as tilted ellipses rather than equal spheres.

```python
# section3_gmm.py
from sklearn.mixture import GaussianMixture

gmm = GaussianMixture(n_components=2, covariance_type="full", random_state=42).fit(Xt)
proba = gmm.predict_proba(Xt)
top = proba.max(axis=1)
print("share assigned with > 0.99 confidence:", round((top > 0.99).mean(), 3))  # ~0.97
print("share genuinely uncertain (< 0.6):    ", round((top < 0.60).mean(), 3))  # ~0.00
```

On this data the mixture is confident: about `97%` of clients are placed with over `0.99` probability, and almost none sit genuinely on the fence. That is itself a finding. It tells you the big-balance group is very cleanly separated from the rest, which is consistent with the decisive silhouette at `K=2`. On messier data the borderline fraction is much larger, and those fence-sitters are exactly the cases a human should review; a hard label would have hidden them.

**Task:** K-means, hierarchical and GMM will each return an answer on *any* data you hand them, including data with no real clusters at all.
