## Exercise 6.2: Try to recover SEX, and compare to just guessing

**Step 1:** Train a small probe to predict `SEX` from the representation, and compare it to the base rate, the accuracy you would get by always guessing the majority group.

```python
# section6_probe.py
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

base = max(sex.mean(), 1 - sex.mean())
print("base rate (guess majority):", round(base, 3))          # ~0.604

def recover(features, label):
    Xtr, Xte, ytr, yte = train_test_split(features, sex, test_size=0.25,
                                           random_state=0, stratify=sex)
    acc = LogisticRegression(max_iter=2000).fit(Xtr, ytr).score(Xte, yte)
    print(f"  {label:38s} acc={acc:.3f}")
    return acc

recover(Xt, "SEX from the FULL representation")               # ~0.612
recover(Z,  "SEX from the 2D PCA representation")              # ~0.605
```

**Step 2:** Check whether the clustering itself lines up with `SEX`.

```python
# section6_ari.py
from sklearn.metrics import adjusted_rand_score
print("cluster/SEX agreement (ARI):", round(adjusted_rand_score(sex, labels), 3))  # ~0.003
```

Read the numbers together. The base rate is `0.604`. The best a probe manages, using *all* 27 features, is `0.612`, barely one point above guessing. From the two-dimensional representation it is essentially the base rate, and the clusters agree with `SEX` no better than chance (an adjusted Rand index of about `0.003`). On *this* dataset, `SEX` is very close to unrecoverable, and dropping the column genuinely does most of the work.

**Reflection:** Now hold this against the lecture. On the synthetic credit data, the same probe recovered the protected group at `0.71`, far above its base rate, because the features there were heavily entangled with the group. Here it recovers `SEX` at `0.612`, barely above `0.604`. *Same method, opposite conclusion.* The lesson is not "dropping the column works" and it is not "dropping the column fails". It is that neither is a law: recoverability is an empirical property of a specific dataset, and the only way to know which world you are in is to run exactly this probe.
