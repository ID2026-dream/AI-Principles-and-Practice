# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | Start Jupyter from inside `week8-lab` |
| `NameError: name 'ls' is not defined` | The first cell was not run | Run the first cell, then continue top to bottom |
| `NameError: name 'my_pca' is not defined` | The Exercise 2 cell was not run | Run the `my_pca` cell, then continue |
| A check says "a line still says None" | A placeholder is still there | Replace `None` with your line and run again |
| `check_my_pca`: "scores do not average to zero" | Data not centred | Step 1 is `X - X.mean(0)` |
| `check_my_pca`: "Divide by n − 1" | Divided by n | Step 4 is `S[:k] ** 2 / (len(X) - 1)` |
| `check_my_information`: "Use np.log2" | Used the natural log | Bits need `np.log2` |
| `load_project` fails | File not in the folder, or no numeric columns | Copy the CSV into `week8-lab`; check its name |
| `make_submission.py` says TODO markers remain | An answer is missing | Finish it, or use `--force` to submit incomplete work |
