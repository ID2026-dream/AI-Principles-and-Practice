# Exercise 1 · Some directions only get longer

**1a · prediction.** Only **(1, 1)** and **(1, −1)** keep their direction, stretched **×4** and **×2**.
*The tempting answer:* the axes (1, 0) and (0, 1), because they look special. They are special for the
identity matrix, not for this one: A turns (1, 0) into (3, 1).

**1b · record.** (1, 1) → (4, 4), same direction ×4; (1, −1) → (2, −2), same direction ×2; (1, 0) → (3, 1),
(0, 1) → (1, 3) and (2, 1) → (7, 5) are all turned.

**1c · explain.** An eigenvector is a *direction*, not a particular arrow. (0.707, 0.707) is (1, 1) scaled to
length 1, so A still only stretches it ×4. NumPy returns length-1 vectors by convention, and either sign.
