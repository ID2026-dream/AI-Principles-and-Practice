**2a · build.**

```python
Xc = X - X.mean(0)                                   # 1. centre
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)    # 2. the SVD
components = Vt[:k]                                  # 3. the top k directions
variance = S[:k] ** 2 / (len(X) - 1)                 # 4. the spread along each
scores = Xc @ components.T                           # 5. the data in the new directions
```
