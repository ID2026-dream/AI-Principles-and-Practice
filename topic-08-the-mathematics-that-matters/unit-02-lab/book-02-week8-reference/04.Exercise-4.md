# Exercise 4 · Build entropy, cross-entropy and KL

**4a · build.**

```python
return float(-(p * np.log2(p)).sum())          # my_entropy
return float(-(p * np.log2(q)).sum())          # my_cross_entropy
return my_cross_entropy(p, q) - my_entropy(p)  # my_kl
```

**4b · prediction.** **About 0.1** (0.133) for 70/20/10, and about **0.8** for 90/8/2.
*The tempting answer:* about 1 bit for 70/20/10, because 70% sounds far from 50%. Small mistakes in the odds
cost little; it is being confident about outcomes you think are rare (2% rain, when it rains 20% of days) that costs a lot.

**4c · record and explain.** Entropy **1.485**, cross-entropy **1.618**, KL **0.133** bits; the four KL values
are **0.000, 0.030, 0.133, 0.812**. The first forecaster believes the real odds, so there is no extra surprise.
KL grows fast at the end because rain gets only 2%: each rainy day then costs −log₂ 0.02 ≈ 5.6 bits.
