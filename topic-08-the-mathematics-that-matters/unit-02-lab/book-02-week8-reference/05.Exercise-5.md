# Exercise 5 · A real model's loss is surprise

**5a · prediction.** **Only a little lower.**
*The tempting answer:* much lower, because the model has 23 features. On this data most of the surprise is
unavoidable: who defaults next month is genuinely hard to predict.

**5b · record and explain.** By hand **0.4720** nats; `log_loss` **0.4720**; "22% default" model **0.5284**
nats (0.762 bits); the features save **0.0564** nats (**0.081** bits) per customer. They agree because log
loss *is* the average of −ln(the probability given to the right answer): the same formula, the same numbers.

**5c · explain.** Week 2's accuracy of 0.81 against 0.78 for "nobody defaults" told the same story in different
units: the features help, but only a little. 0.08 bits per customer is a small amount of information.
