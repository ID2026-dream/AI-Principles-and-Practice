# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | Start Jupyter from inside `week9-lab` |
| `NameError: name 'ls' is not defined` | The first cell was not run | Run the first cell, then continue top to bottom |
| A check says "returns None" | A placeholder is still there | Replace `None` with your line and run again |
| `check_my_lora`: "should return a 6 × 5 table" | Multiplied A @ B, or element by element | Use `B @ A` |
| `check_my_augment`: "repeat the labels" | Labels not repeated once per copy | Keep `np.tile(y, len(copies))` |
| `check_my_carbon`: "Divide watts by 1,000" | Forgot kilowatts | `watts * hours / 1000` |
| A later cell says "Finish Exercise 4 first" | The build above is not finished | Make its check show ✓, then rerun |
