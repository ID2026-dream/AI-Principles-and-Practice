# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| The first `from_pretrained` call hangs | The models were not pre-cached | Run `python precache_models.py` before the lab. In the lab, start Sections 1 and 2 first and let the download finish while you read. |
| `pip install torch` says *no matching distribution* | Your Python is newer than PyTorch's wheels | Make a Python 3.12 environment for this lab (see the first page) |
| `FileNotFoundError: train.csv / test.csv not found` | The data is not in the folder you started Jupyter from | Start Jupyter inside `week10-lab`, or run `python get_data.py` |
| `(120000, 4)` is not printed | The CSVs are not the original AG News files | Run `python get_data.py`: it checks both files and downloads them again if needed |
| `out.attentions` is `None`, or a warning about `sdpa` | A fast attention kernel that does not return weights | Load the model with `attn_implementation="eager"`, as the notebook does |
| Every Sci/Tech headline is marked wrong in Section 2 | Answers marked against "Sci/Tech" while the model chooses "Technology" | Use `ICL_NAME` for both the examples and the marking, as the notebook does |
| The probe step is slow | A transformer on a CPU over 1,800 headlines, three times | Drop the sample size or `max_length`; the pattern survives |
| Your numbers differ from the ones quoted | The model-dependent numbers depend on the checkpoint and the sample | Expected. The 0.924 baseline and the memory figures should match closely; for the rest, **your number is the finding** |
