# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | Start Jupyter from inside `week11-lab` |
| `ModuleNotFoundError: scipy` | scipy missing | `pip install -r requirements.txt` |
| A check says "returns None" | A placeholder is still there | Replace `None` with your line and run again |
| `check_my_noisy`: "Use square roots" | Mixed the shares without square roots | `np.sqrt(abar_t) * x0 + np.sqrt(1 - abar_t) * eps` |
| `check_my_loss`: "Square each miss" | Used the absolute miss | `((eps - guess) ** 2).mean()` |
| `check_my_langevin`: "Go downhill" | Added the slope instead of subtracting it | `x - step * slope + ...` |
| A later cell says "Finish Exercise N first" | The build above is not finished | Make its check show ✓, then rerun |
| "Train the denoiser first" | Exercise 2's training cell was not run | Run `ls.train_denoiser(my_loss)` |
| `check_my_leftover` fails on the third line only | Friction left out (the first two tests have no speed) | `m * ddu + c * du + k * u` |
