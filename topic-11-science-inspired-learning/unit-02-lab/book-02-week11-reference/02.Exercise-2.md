# Exercise 2 · Learn to undo it

**2a · build.** `return float(((eps - guess) ** 2).mean())`

**2b · prediction.** **About 0.3** (0.295 over the last 500 steps).
*The tempting answer:* near 0, because the network keeps improving.

**2c · record and explain.** First 100 steps: 0.460; last 500: 0.295; guessing zero would score about 1.0. A given noisy point
could have come from many different starting points with different noises, especially at the last steps where almost nothing of
the original is left. The best any guesser can do is the *average* noise for that noisy point, so some miss always remains.
