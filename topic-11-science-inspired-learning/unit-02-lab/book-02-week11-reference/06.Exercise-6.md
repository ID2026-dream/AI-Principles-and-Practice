# Exercise 6 · Build the symmetry in

**6a · build.** `return np.sqrt((X ** 2).sum(1))`

**6b · prediction.** The raw network **fails** on the unseen quarters (55.2%, about a coin toss); the distance model gets
**100%**.
*The tempting answer:* the network is flexible enough to work out that only the distance matters.

**6c · record and explain.** Both score 100% on the quarter they trained on. On the other three quarters the raw network
has never seen any points there, so it has no idea what to do: it learned "the top-right quarter", not "the distance from the
centre". The distance from the centre does not change when a point is turned around the centre, so the distance model gives the
same answer everywhere: it cannot fail on a turned point.

**6d · change one thing.** The distance model stays **near 50%** (51.1%, 48.4%, 51.6% at 100, 1,000 and 10,000 points);
the raw network reaches 98.6%, 99.7% and 99.9%.
*The tempting answer:* with enough data, any model learns it. But the distance model never sees the angle, and the angle is
now the whole answer: two points at the same distance, one in each half, look identical to it. No amount of data can show it
something it is not allowed to read. A false symmetry is a wall.

**L1.** A diffusion model learns to guess the noise that was added, and so to undo noise step by step. A neural ODE is a network
whose layers are small steps of a learned rule of motion. Building a symmetry in means the model is right on every turned or
shifted version for free, instead of needing examples of each.
