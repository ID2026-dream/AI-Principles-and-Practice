# Lab (2h 35min)

Eight exercises, in the same order as the lecture. In each you predict first, run, and explain in your own words; in six you build one line yourself. In Exercise 7 you teach a network with zero data, using only the equation (a physics-informed network, as in elective E6), see its two quiet failures, and find an unknown friction with a simulator (physics-informed ML, as in E5). Everything runs in NumPy; the longest cell takes about 10 seconds.
